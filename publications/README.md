## Reference Implementations

The primary open-source [API & Integration Testing Framework](https://github.com/ashokmanohar-ai/api-integration-testing-framework) demonstrates typed REST/GraphQL clients, Pydantic models, positive/negative/boundary/RBAC tests, Pact V4 contracts, SQLAlchemy persistence checks, WireMock dependency failures, transactional outbox events, Redpanda integration, retries, idempotency, correlation IDs, parallel-safe data, JUnit/HTML reporting and CI quality gates.

The supporting [Agentic Quality Engineering Platform](https://github.com/ashokmanohar-ai/agentic-quality-engineering-platform) demonstrates complementary patterns for specialized AI agents, structured outputs, deterministic quality controls, evidence-preserving orchestration, governed execution and failure triage.

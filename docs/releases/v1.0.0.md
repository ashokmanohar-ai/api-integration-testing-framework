# v1.0.0 — API & Integration Quality Engineering Reference

This first stable portfolio release demonstrates enterprise API and integration assurance across interfaces, contracts, data, events, dependencies and business side effects.

## Included evidence

- typed REST and GraphQL clients with Pydantic request/response/error contracts
- Pact V4 consumer tests and provider verification against the real FastAPI service
- RBAC, negative, boundary and security-oriented API scenarios
- SQLAlchemy persistence checks and transactional outbox event validation
- WireMock dependency failures, bounded retries, idempotency and recovery evidence
- SQLite fast mode plus PostgreSQL and Redpanda Docker integration mode
- a 66-second recruiter walkthrough and five-minute smoke path

## Verification

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev,messaging,postgres]"
pytest -m smoke
pytest -m contract
```

## Scope and limitations

This is a synthetic Acme Order reference application. It demonstrates architecture and failure modes without representing customer data, production throughput or a production messaging topology.
